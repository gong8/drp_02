Frontend · @bethere/mobile
  • Expo + React Native - one codebase ships to iOS, Android and web
  • Every screen is one typed tRPC call - events.create, respond, joinByCode
  • Clerk (third-party) for Google sign-in; the web target makes no-download onboarding possible
Backend · @bethere/api
  • Fastify 5 + tRPC v11 on Node - the events, groups + users routers, 32 typed procedures
  • The demo as real endpoints: create → toggleReaction → lock → respond → resolve
  • Zod validates every input; phases settle on read - no scheduler
Data · Postgres
  • Postgres - 10 relational tables give us integrity for free
  • Drizzle ORM - fully typed SQL, no hand-written query types
  • The privacy guarantees live inside the queries, out of the client’s reach
Shared core · @bethere/shared
  • Zod schemas + framework-free logic - vote tally, conditional-RSVP, blind reveal
  • One source of truth feeds the same types + validation into client and server
  • A change that would break the client fails at compile time, not in front of a user
Deployment · Git → CI → CD
  • Every push runs lint, typecheck and tests on GitHub Actions
  • Ships Android APK, web → Vercel, API → AWS App Runner (Docker)
  • A deployed build real friends used on their own phones - iOS, Android, web
