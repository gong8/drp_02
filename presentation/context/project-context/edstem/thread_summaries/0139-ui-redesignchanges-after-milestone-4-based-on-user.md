# #139 — UI redesign/changes after Milestone 4 based on user feedback

`source: edstem thread #139`

**Question:** A student asks whether it is acceptable to significantly redesign the app's UI (colour schemes, layout, overall look and feel) after Milestone 4 in response to user feedback, given that the core concepts remain the same.

**Answer (Jamie Willis):** This is fine.

**Answer (Mark Wheelhouse):** Yes, making changes after Milestone 4 in response to user or tutor feedback is no problem. The final presentation should showcase the project as a "finished product"; only a small amount of discussion about the design/development process is expected.
