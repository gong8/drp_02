# #58 — Multiplatform solution viability

`source: edstem thread #58`

**Question:** Can groups build multi-platform solutions (e.g. desktop + mobile), and is this advised given potential time or other constraints?

**Answer (Zaki Amin):** A web app is the simplest and least time-intensive way to target both desktop and mobile. Unless there is a specific, demonstrable user need for a multi-platform solution, it is inadvisable due to the extra development effort.

**Answer (Mark Wheelhouse):** Agreed. Past groups have managed to build multi-platform services, but it only makes sense if there is a clear user-driven need for it.
