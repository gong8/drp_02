# #131 — Presenting Apps

`source: edstem thread #131`

**Question:** How should a group best demo a mobile app in the final presentation — is an emulator sufficient? Also, how should geofencing/geo-location functionality be demoed given it is hard to replicate live?

**Answer (Mark Wheelhouse):** The app must be shown running live on a real phone for at least part of the presentation (connect via USB-C or use the visualiser available in HXLY 145/308/311, with setup assistance available at the start of the slot). For geo-location features specifically, either spoofing the location in an emulator or showing a short pre-recorded video is acceptable, provided the app is still seen running live on a phone elsewhere in the presentation. Groups have complete freedom in how they present, but authenticity is key — showing the app only in an emulator risks not earning full "Stable Product" marks.
