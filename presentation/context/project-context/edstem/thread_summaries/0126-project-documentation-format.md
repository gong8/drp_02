# #126 — Project documentation format

`source: edstem thread #126`

**Question:** A student asked how to format the HCD Techniques Portfolio submission — whether it should be a single curated document or separate files — and whether supporting stakeholder evidence (recordings, transcripts, notes) beyond quotes in technique documents should also be included.

**Answer (Mark Wheelhouse):** The DRP Project Documentation submission on Scientia (due Friday 19th June) consists of three separate PDF deliverables:
- Project Pitch Leaflet
- Copyright/Legal Issues Report
- Human Centred Design Techniques Portfolio

The HCD Techniques Portfolio must be a single curated PDF document consolidating all design materials produced during the project. Supporting stakeholder evidence (e.g. transcripts, notes, research analysis) should be included in text form where relevant, since PDF does not support video/audio. Quality over quantity — curate to the most impactful evidence, guided by the assessment criteria (to be discussed in Monday's session). Full format details are in the Assessment Overview document (linked in thread #24).
