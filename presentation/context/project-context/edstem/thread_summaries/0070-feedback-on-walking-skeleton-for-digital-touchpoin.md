# #70 — Feedback on walking skeleton for digital touchpoint

`source: edstem thread #70`

**Question:** For the third marking point (Quality of feedback and validation of concept), is user interaction with the deployed digital touchpoint required by the end of the current week, or is evidence from mockups and clickable prototypes sufficient?

**Answer (Mark Wheelhouse):** There is no requirement to have conducted user testing on the Walking Skeleton for the current week. Feedback gathered via mockups and prototypes alone is sufficient to access the full range of interaction and feedback marks. If user testing on the deployed touchpoint has been done and yielded interesting or impactful findings, that is welcome but not mandatory. The following week, however, some user engagement with the deployed service is expected — at least for refining the core interaction. New interfaces or interactions are still best developed via mockups and prototypes initially.
