# #111 — Further developing existing stories

`source: edstem thread #111`

**Question:** Can students apply Milestone 4 work (such as KPIs/metrics) to existing stories to further develop the UX, rather than working on an entirely new theme?

**Answer (Mark Wheelhouse):** Applying a metric/KPI to existing work is acceptable as long as the student is actively developing that part of the system this week. However, not working (at least mostly) on a new theme carries significant risk of failing to get the digital touchpoint into a near-finished state by the end of the week — which is the last full development week.
