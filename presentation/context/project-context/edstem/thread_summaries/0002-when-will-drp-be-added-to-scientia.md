# #2 — When will DRP be added to Scientia?

`source: edstem thread #2`

**Question:** A student asked when Scientia would be updated with correct information for DRP and the rest of Summer Term, following up on thread #1.

**Answer (Mark Wheelhouse):** The DRP project schedule will be uploaded to Scientia by the start of Spring term (possibly earlier). Other module resources will be uploaded throughout the project iterations. DRP is the only module running in Summer term of Year 2 (JMC students have the option to take the Maths Group Project instead).
