# #41 — DRP Pitch

`source: edstem thread #41`

**Question:** A student asked whether the three-minute pitch should be entirely pre-recorded or could mix live speaking with recorded content.

**Answer (Mark Wheelhouse):** The Elevator Pitch presentation must be entirely pre-recorded — no live speaking component is permitted. This requirement exists to enforce the strict 3-minute time limit fairly and consistently across all groups.
