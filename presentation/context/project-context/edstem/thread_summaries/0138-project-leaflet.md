# #138 — Project leaflet

`source: edstem thread #138`

**Question:** A student was told by their DRP tutors in the week 4 milestone meeting to consider a double-sided (two sides of A4) project pitch leaflet, but the DRP assessment template states only one side of A4 is allowed — asking whether the two-sided format is permitted.

**Answer (Mark Wheelhouse):** Double-sided leaflets are allowed only in two specific cases: (1) if the leaflet is designed to be folded in real life (note that margins will consume significant space), or (2) if it is an A5 "postcard" style, where both sides fit on a single A4 side anyway. Any other format (e.g. poster, advert) must be single-sided since the back would not be visible to the audience. Regardless of format, the total text content across the document must not exceed one A4 side — this ensures a level playing field and limits time spent. Multiple pitch leaflets may be included in the HCD Techniques Portfolio if desired, but should not be excessive.
