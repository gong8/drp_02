# #7 — Marks for DRP

`source: edstem thread #7`

**Question:** A student asked whether the DRP (Design Research Project) is part of CP2 or a separate module, and how much it contributes to the final Year 2 grade.

**Answer (Mark Wheelhouse):** DRP is its own 5 ECTS module (COMP50010), separate from CP2. It contributes 5/60 to the Year 2 grade, which equals 8.33%.
