# #64 — Walking Skeleton Expectations

`source: edstem thread #64`

**Question:** What are the specific expectations for the Walking Skeleton deliverable in DRP Milestone 2?

**Answer (Mark Wheelhouse):** The Walking Skeleton requirements for Milestone 2 are:

- The digital touchpoint must be deployed to a public server (not localhost) or a physical mobile device (not an emulator only).
- The deployed code must be end-to-end complete: Front-End and Back-End fully connected, with a demonstrable flow where a Front-End interaction is sent to the Back-End (and optionally saved), then visualised back in the Front-End. This will be demoed.
- A full CI/CD pipeline must be set up, including at minimum compilation checking and automated continuous deployment. This must also be demoed.

The purpose is to resolve all technical setup hurdles upfront so there are no barriers to showing work each week and getting changes to users for testing.
