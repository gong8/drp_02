# #33 — DRP Projects: Copyright and NDAs

`source: edstem thread #33`

**Question:** This staff announcement addresses copyright ownership of DRP project code and how students should handle requests to sign NDAs from potential external collaborators.

**Answer (Mark Wheelhouse):**
- Copyright for DRP project code belongs to the students (the authors), not Imperial or any external collaborators.
- If anyone asks you to sign an NDA during project discussions or research, refuse and walk away — the project scope does not warrant it, and the DRP assessment panel will not sign an NDA just to mark your work.
- Anything produced will be at most a highly functioning prototype or proof-of-concept, so the code likely has very little intrinsic value.
- External collaborators you approach may not be aware of this; Mark is willing to chat with potential collaborators about code ownership at the project's end — deal with such matters early to avoid disagreements later in the term.
