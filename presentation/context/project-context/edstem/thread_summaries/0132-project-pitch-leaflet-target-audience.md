# #132 — Project Pitch Leaflet Target Audience

`source: edstem thread #132`

**Question:** A student group with two stakeholder groups (psychologists and couple clients) asked whether their project pitch leaflet should target psychologists only (who then direct clients to the app) or address both stakeholder groups simultaneously.

**Answer (Mark Wheelhouse):** The choice is up to the group, but focusing the leaflet on psychologists is reasonable — just be sure to also "sell" the benefit the service provides to their clients. A separate leaflet aimed at clients (e.g., something couples might see in a waiting room) is also an option. Regardless of approach, the term "preventative couples therapy" must be defined somewhere in the leaflet(s), as it is central to the project but not widely known.
