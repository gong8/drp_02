# #43 — Do we need to be in the recording directly?

`source: edstem thread #43`

**Question:** A student asked whether they needed to appear on camera in the pitch recording, or whether a voice-over on slides would suffice.

**Answer (Mark Wheelhouse):** It is entirely up to you — appearing on camera is not required. The pitch must be pre-recorded (presented to the assessment team the following day), and any awkward moments (e.g. whispering to a teammate to advance slides) should be avoided in the recording, but whether presenters are visible on screen is the team's own choice.
