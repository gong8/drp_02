# #107 — Why do we need to make a group for the milestone?

`source: edstem thread #107`

**Question:** A student noticed an unexpected prompt to create a group when submitting a milestone, which had not appeared in previous milestones, and asked why it was required.

**Answer (Mark Wheelhouse):** This is an unintended side effect of EdStem changes made by EdTech the previous week to support forced group creation for uploading Milestone 3 feedback and marks. Students should not create groups here — doing so will interfere with feedback post-processing. Mark indicated he would follow up with EdTech to find a way to disable this specific interaction.
