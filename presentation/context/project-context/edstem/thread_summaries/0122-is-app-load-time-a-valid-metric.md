# #122 — Is app load time a valid metric?

`source: edstem thread #122`

**Question:** A student asked whether app load time is a valid metric for their app, noting that users might open it multiple times throughout the day.

**Answer (Jamie Willis):** No — app load time is a pure optimisation problem and cannot be influenced or improved through user interactions, making it an unsuitable metric.

**Answer (Mark Wheelhouse):** Agreed. App load time is a poor metric choice because it has nothing to do with user interactions with the service. The goal should simply be to ensure load time is not too long, not to track it as a meaningful interaction metric.
