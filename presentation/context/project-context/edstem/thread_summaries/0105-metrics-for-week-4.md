# #105 — Metrics for week 4

`source: edstem thread #105`

**Question:** A student asked whether the metrics required for week 4 should cover the entire digital touchpoint or only the work done during that week's sprint.

**Answer (Mark Wheelhouse):** The metrics are meant to augment qualitative user feedback sessions, so the focus should be on gathering data during the current week's work. Collecting some baseline data for a chosen metric at the start of the week is also reasonable.

**Answer (Zaki Amin):** Metrics cannot be collected retroactively, so teams should start defining and gathering them as soon as possible. It is fine if the metrics involve measuring interactions that began in previous iterations.
