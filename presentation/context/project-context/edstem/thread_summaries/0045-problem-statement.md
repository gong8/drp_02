# #45 — Problem Statement

`source: edstem thread #45`

**Question:** A student asked whether the problem statement needs to be included in the slides, or whether only the "How Might We" (HMW) is required.

**Answer (Jamie Willis):** Both the problem statement and the HMW should be included.

**Answer (Mark Wheelhouse):** The opportunity statement (HMW) is mandatory to avoid missing that assessment criterion entirely. Including a problem statement slide is left to your own judgement — it can help clarify the pitch when the problem isn't already obvious from the rest of the presentation. Also note that the problem statement and opportunity statement are not the same thing; refer to the examples in the Milestone 0 section of the Assessment Template, the DRP Playbook, and the HCD Workshop slides if unsure.
