- Students must be present for the **whole** hour of their allocated session (see the [DRP - Milestone Assessment Schedule](https://imperiallondon-my.sharepoint.com/:x:/r/personal/mjw03_ic_ac_uk/Documents/DRP%20-%20Milestone%20Assessment%20Schedules%20(read%20only%20again).xlsx?d=w5121fcb27e334f74ac82a8e0f5bdfeb8&csf=1&web=1&e=r2KPzu)).
- The running order within each session is randomised and will not be announced in advance.
- Students should check which Assessment Stream (and hence room) they have been allocated to — a small number of groups were moved from Stream A to Stream B to rebalance the schedule, though no one was moved to a different overall session time.
