# #91 — Why is there no peer assessment for DRP as there was for PintOS and WACC?

`source: edstem thread #91`

**Question:** A student asks why there is no peer assessment for DRP, unlike in the PintOS and WACC projects.

**Answer (Mark Wheelhouse):** Peer assessment will be included for DRP, but it will come towards the end of the project. The timeframe is too short to run multiple peer assessments for each week or milestone.
