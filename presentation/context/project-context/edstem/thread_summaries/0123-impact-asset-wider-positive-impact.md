# #123 — Impact Asset Wider Positive Impact

`source: edstem thread #123`

**Question:** A student asked whether the impact asset can present a future, pivoted version of the solution targeting different stakeholder groups, and whether such groups would count as direct or indirect impact — or whether only the wider indirect impact of the current solution should be shown.

**Answer (Mark Wheelhouse):** The impact asset should present an ideal future state of the project (approximately 4–6 months ahead), assuming ideal user take-up and data entry. However, the general functionality and target stakeholder groups should remain closely related to the current solution, otherwise it risks appearing as an entirely different project. Any stakeholder groups who are direct users of the service count as direct impact; to satisfy the "wider positive consequences" criteria, the focus must be on the indirect benefits the service provides to others beyond direct users.
