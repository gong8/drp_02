# #95 — Themes, Journeys, Stories and Iterations (Thin Slices)

`source: edstem thread #95`

**Question:** Staff announcement clarifying how themes, user journeys, user stories, and thin-slice iterations should relate to each other in Milestone 2 work and Friday presentations.

**Answer (Mark Wheelhouse):** For the week's work and Friday presentation, teams should structure their progress as follows:
- Set a clear **theme** focused on a specific aspect of the chosen problem.
- Identify the **user journeys** affected by that theme, ideally tied to a specific user persona.
- Define concrete **user stories/needs** that describe specific interactions with the service to be implemented.
- Implement the solution across several **iterations (thin slices)**, refining the interaction/interface to fulfil each user story.

Crucially, there is **not** a 1:1 correspondence between user stories and thin slices — the relationship is many-to-one: it will typically take multiple iterations/thin slices to refine a good interaction that satisfies a single user story.
