# #93 — What is the procedure for loaning a device from labs?

`source: edstem thread #93`

**Question:** A student whose team is developing on Android asked how to borrow an Android device from the labs, or alternatively how to run Android Studio on lab machines.

**Answer (Mark Wheelhouse):** Visit CSG and they should be able to lend out Android devices (noting they are rather old). Alternatively, many TFs in HXLY 306 have the key to the cupboard where these devices are kept.
