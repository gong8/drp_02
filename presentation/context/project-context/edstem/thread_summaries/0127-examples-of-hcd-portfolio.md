# #127 — Examples of HCD Portfolio

`source: edstem thread #127`

**Question:** A student asked whether there are any examples of past HCD portfolios to understand the expected general structure.

**Answer (Mark Wheelhouse):** Sharing previous submissions is not appropriate without prior permission from those groups, and the content is always project-specific. However, the HCD Portfolio should be a single PDF containing research documents produced during the project, where roughly each row of the HCD Portfolio Assessment grid corresponds to a document or type of document. Expected contents include:

- AEIOU of Field Research (Activities, Environments, Interactions, Objects, Users)
- User persona documents
- Stakeholder mapping diagram(s)
- User Journey Maps (before and after experience)
- Initial qualitative research (key interview feedback and analysis leading to core insights)
- Project Problem Context and Opportunity Statement
- Examples of user interviews/feedback generated during the project (most impactful insights)
- Examples of project development (mock-ups to prototypes to digital touchpoint evolution) with supporting user feedback motivating changes
- Project Impact Asset(s) showing benefits to stakeholder(s)

Presentation format is flexible, but all the above must be covered. Supporting text should be minimal — roughly 1–2 A4 sides in total, similar in scope to the true concurrency report.
