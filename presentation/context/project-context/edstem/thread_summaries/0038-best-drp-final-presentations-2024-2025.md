# #38 — Best DRP Final Presentations 2024-2025

`source: edstem thread #38`

**Question:** This thread is a staff announcement sharing a collection of exemplary DRP final presentations from the previous academic year (2024-2025) to help current students prepare.

**Answer (Mark Wheelhouse):** A [Panopto folder of the 7 best DRP Final Presentations from 2024-2025](https://imperial.cloud.panopto.eu/Panopto/Pages/Sessions/List.aspx?folderID=c48136fc-772c-4b46-869e-b44a008e5134) has been uploaded (a couple of videos were still processing at time of posting). Two ways these recordings can help:
- They can help refine your own problem framing for this year's project.
- Each presentation opens with a ~3-minute overview of the project context and problem/opportunity statement, which is useful for planning your project pitch presentations due this Friday — noting that you are at an earlier project stage and have a stricter time limit this week.
