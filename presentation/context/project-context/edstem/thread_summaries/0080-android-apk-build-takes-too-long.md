# #80 — Android APK build takes too long

`source: edstem thread #80`

**Question:** A student asked whether it is normal for their CI/CD pipeline on a free GitHub runner to take around 16 minutes to build a React Native project into an Android APK, and how to handle demonstrating a pipeline build during the Milestone Checkpoint on Friday.

**Answer (Mark Wheelhouse):** Yes, long build times are typical with free-tier services. For the milestone review sessions that week, staff will ask groups to push a front-end change into their pipeline at the very start of the session, then return to check the result at the end. Any pipelines that run even longer will be handled on a case-by-case basis.
