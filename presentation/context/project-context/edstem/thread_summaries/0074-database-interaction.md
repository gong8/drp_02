# #74 — Database Interaction

`source: edstem thread #74`

**Question:** A student asks whether Milestone 2 requires a database interaction that visibly manifests changes in the frontend, noting they could only recall the requirement for a connected frontend and backend rather than any explicit database interaction criterion.

**Answer (Mark Wheelhouse):** The requirement for this milestone is a complete end-to-end walking skeleton with the frontend fully connected to the backend. Ideally this should involve the persistent storage solution the group plans to use for the project, but persistence itself is not what is being assessed at this stage. Demonstrating frontend-to-backend connectivity (as explained in lectures and EdStem posts #64 and #71) is sufficient.
