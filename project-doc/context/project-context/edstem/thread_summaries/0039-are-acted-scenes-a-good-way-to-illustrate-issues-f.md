# #39 — Are acted scenes a good way to illustrate issues faced by people (NOT personas....) in the pitch video for Friday?

`source: edstem thread #39`

**Question:** A student asked whether including acted scenes in the pitch video is worthwhile or overkill, and later whether acted scenes add value when interview videos are already available.

**Answer (Jamie Willis):** Acted scenes can be effective if done well, but the actor is representing the persona. They serve to tell the user journey, which interviews can support evidentially but cannot capture on their own — though striking the right balance is important.

**Answer (Mark Wheelhouse):** This approach can work if done sensibly, but the context and type of user must be made clear — which can be tricky when the actor is very different from the persona (e.g. a student playing an elderly person). Video of actual interviews is nearly always an easier and more effective option, assuming participants agree to it.

**Answer (Zaki Amin):** If the acting creates a throughline and narrative that couldn't be achieved otherwise, it adds value — but be careful not to let it detract from the pitch's focus and the actual evidence.
