# #10 — The Empathic Engineer Website

`source: edstem thread #10`

**Question:** Following the HCD Introduction lecture series, what website resource was shared to support students in working as impactful innovators?

**Answer (Mark Wheelhouse):** Nick requested sharing the website [https://www.empatheticengineer.org/](https://www.empatheticengineer.org/), which explores how to work as an "impactful innovator" in empathic, systematic, and creative ways. The site includes links to process guides, tools, resources, and case studies that students may find useful for their own project work during the Summer term.
