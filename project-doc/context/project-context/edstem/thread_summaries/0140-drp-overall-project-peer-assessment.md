# #140 — DRP - Overall Project Peer Assessment

`source: edstem thread #140`

**Question:** This is a staff announcement about the Overall Project Peer Assessment survey for COMP50010 students.

**Answer (Mark Wheelhouse):** A DRP Overall Project Peer Assessment (PA) survey has been created on the [DoC Peer Assessment platform](https://peer-assessment.doc.ic.ac.uk). Key details:

- The survey is already open and closes at **20:00 on Friday 19th June**.
- All COMP50010 students are expected to participate.
- Expected scores are 3–4 for groups with no issues; scores outside this range signal to organisers that a group may need a check-in.
- There is no automatic mark scaling based on PA scores, but results will be considered when resolving group work disputes.
- Free-text feedback can be provided to peers; it must be constructive and professionally toned, and will be moderated before being released privately to students.
