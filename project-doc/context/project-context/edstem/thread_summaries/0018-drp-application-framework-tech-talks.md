# #18 — DRP Application Framework Tech Talks

`source: edstem thread #18`

**Question:** This thread is a staff announcement about the availability of recorded tech talks for DRP application frameworks.

**Answer (Mark Wheelhouse):** Five DRP Application Framework Tech Talk recordings have been uploaded to Panopto (in a sub-folder of the main DRP Panopto folder). The talks are independent and can be watched in any order; none are mandatory. They are listed below in order of framework popularity from past years:

- JavaScript/React (~42 mins)
- iOS Development with Swift (~50 mins)
- Scala JS (~57 mins)
- Python/Flask (~43 mins)
- Python/Django (~25 mins)

The talks cover how to get started with a simple application in each framework. Students do not need to act on this until the second week of the DRP project (25–29 May), but are encouraged to start thinking about their preferred tech stack beforehand.
