# #24 — DRP Assessment Information

`source: edstem thread #24`

**Question:** A student asked why the assessment criteria in the DRP Assessment Template only adds up to 90% of the marks, and what the remaining 10% is for.

**Answer (Mark Wheelhouse):** The DRP Assessment Template covers 90% of the module marks. The remaining 10% comes from the Introduction to LAW TRA (visible in the assessment breakdown on Scientia), which is deliberately excluded from the template because it is an MCQ-style assessment and including it would give away the answers. Mark also announced that at the start of each week, Carolyn Runcie and Mark Wheelhouse will hold a dedicated Q&A session to discuss that milestone's assessment criteria; attendance is highly encouraged (sessions are recorded via Panopto, but in-person attendance allows immediate clarification of any confusion).
