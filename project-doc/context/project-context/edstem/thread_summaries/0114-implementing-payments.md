# #114 — Implementing Payments

`source: edstem thread #114`

**Question:** If a project includes a payment feature, does it need to process real payments, or is a mock/prototype payment flow sufficient? The student notes that real payment testing would require users to provide sensitive payment details.

**Answer (Jamie Willis):** Mock it.

**Answer (Mark Wheelhouse):** Agreed — real payments would be problematic for user testing and could expose the team to legal issues. Fake the interaction for now and explain that it would be connected to a real payment service in the future.
