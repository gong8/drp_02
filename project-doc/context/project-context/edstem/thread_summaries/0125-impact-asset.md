# #125 — Impact Asset

`source: edstem thread #125`

**Question:** A student asks whether they need to improve their Impact Asset before the final presentation, noting it does not appear to be assessed on the presentation template.

**Answer (Mark Wheelhouse):** You do not need to present the Impact Asset during the DRP Final Presentation. However, you should improve it (based on feedback received) before the Human Centred Design Techniques Portfolio submission, which is part of the DRP Project Documentation exercise on Scientia, due Friday 19th June.

**Answer (Jamie Willis):** You will still need to talk about impacts/benefits during the final presentation, so it is worth thinking about that content from your Impact Asset — even if it does not take the same form.
