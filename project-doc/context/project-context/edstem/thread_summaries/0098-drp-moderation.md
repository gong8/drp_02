# #98 — DRP Moderation

`source: edstem thread #98`

**Question:** A student asked whether there will be moderation for DRP, what it will be based on given that code is not reviewed, and when it will take place.

**Answer (Jamie Willis):** Yes, there will be a single peer assessment at the end covering the whole project. Staff will follow up with groups that have flagged issues. However, moderation is more conservative than usual given the nature of DRP — for example, writing no code does not necessarily mean a student did not contribute significantly.
