# #134 — Problem Statement vs Opportunity Statement

`source: edstem thread #134`

**Question:** The final presentation assessment criteria mentions a "Clear Problem Statement" but does not explicitly mention the opportunity statement / "How Might We" statement. Students asked which one(s) should be included, noting that many top presentations from the previous year used an opportunity statement rather than a problem statement.

**Answer (Mark Wheelhouse):** The assessment criteria are general categories, not a checklist of specific items. The "Clear Problem Statement" criterion covers how well the project context and problem are defined, which should include the "How Might We" opportunity statement. More detail will be discussed in the Monday session. See thread #110 for a full breakdown of the expected elements in the final presentation.
