# #124 — project pitch leaflets

`source: edstem thread #124`

**Question:** A student asks where to find examples of good project pitch leaflets, and where to upload the project pitch leaflet given that the final presentation schedule spreadsheet only appears to have a column for the project impact asset.

**Answer (Mark Wheelhouse):** Examples of project pitch leaflets can be found on the [Best Second Year Group Projects website](https://www.imperial.ac.uk/computing/current-students/course-admin/noticeboards/second-year/projects/best-projects/) — click on any group's carousel item to reach its sub-page. The spreadsheet column label was a mistake; it has been corrected to read "Project Pitch Leaflet".
