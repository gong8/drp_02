# #22 — Fun/Lighthearted projects

`source: edstem thread #22`

**Question:** A student asks whether fun or lighthearted projects (such as games) are permitted and can still achieve a good grade, and whether the problem being solved needs to be a serious issue affecting people.

**Answer (Jamie Willis):** Lighthearted projects can work well — what matters is not what you build but how you identified a real problem, engaged with the people it affects, and built something that genuinely puts those people first. The focus is on the human-centred design process and the journey (storytelling of the problem, what you learned from users) rather than on technical complexity or the severity of the issue. The project does not need to address a grand humanitarian cause.

**Answer (Mark Wheelhouse):** Older example WebApps projects came from a time when assessment criteria were entirely different (HCD was a separate parallel project, not unified into the one module), so they are not a reliable guide. Building a game without a clear, demonstrated need for it is unlikely to perform well under the current assessment criteria.
