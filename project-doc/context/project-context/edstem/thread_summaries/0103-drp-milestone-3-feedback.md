# #103 — DRP Milestone 3 Feedback

`source: edstem thread #103`

**Question:** This is a staff announcement regarding the return of Milestone 3 feedback and guidance on the Scientia submission group process.

**Answer (Mark Wheelhouse):** Milestone 3 feedback has been uploaded to Scientia via the new DRP Marking Wiki feedback return process; Milestones 1 and 2 feedback is also now accessible. Nearly every group improved this week despite more demanding assessment criteria. The criteria do not shift again for Milestone 4, so further improvement is expected as long as groups continue acting on tutor feedback.

**Answer (Jamie Willis):** Do not form submission groups yourself in Scientia. The process automatically creates groups from staff data, force-accepts members, and uses those groups to upload feedback. Manually created groups must be deleted before the process can run correctly, causing hiccups.
