# #16 — Hosting?

`source: edstem thread #16`

**Question:** A student asked for suggestions on what to use for hosting sites and databases, with a preference for free-tier options unlikely to hit limits during the coursework.

**Answer (Mark Wheelhouse):** The choice of hosting is up to each group's own preferences. The project overview document (uploaded to Scientia) includes suggestions for hosting via DoC services in the appendix, though there are limitations to that approach (as experienced in the DevOps exercise). Tsuru (used in the DevOps exercise) is also an option if groups preferred working that way.
