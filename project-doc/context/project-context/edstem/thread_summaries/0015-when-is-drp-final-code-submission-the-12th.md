# #15 — when is DRP final code submission? the 12th?

`source: edstem thread #15`

**Question:** A student asks when the DRP final code submission deadline is, suggesting it might be the 12th.

**Answer (Mark Wheelhouse):** There is no code submission for the DRP project — unlike PintOS or WACC, it is not assessed on code. Assessment is based on: the process followed (evaluated during project milestone review sessions), the final project outcome (assessed via presentation), and a small portfolio of supporting documentation submitted by Friday 19th June.
