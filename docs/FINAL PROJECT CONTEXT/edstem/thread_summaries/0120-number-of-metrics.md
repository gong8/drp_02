# #120 — Number of metrics

`source: edstem thread #120`

**Question:** A group with two stakeholders (one using an app, one using a website) asks whether it is acceptable to present two distinct metrics — one per platform — rather than merging them into a single, less meaningful combined metric.

**Answer (Mark Wheelhouse):** Do not merge specific metrics into one vague metric, as that reduces meaning. Focus the presentation on the **one** metric that had the most significant impact on your work that week, or that was analysed in the most detail. Assessment is based on the **quality** of the metric and its analysis, not the number of metrics tracked.
