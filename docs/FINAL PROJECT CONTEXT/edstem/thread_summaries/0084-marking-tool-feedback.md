# #84 — Marking tool feedback

`source: edstem thread #84`

**Question:** A student asks whether there is a dedicated place to give feedback on the marking tool, noting that as recipients of the feedback they are stakeholders in the HCD process.

**Answer (Mark Wheelhouse):** Students are welcome to chat with Mark and Jamie during Clinic Hours the following week. Mark also set up thread #86 as a dedicated mega-thread (with anonymous comments enabled) for this feedback. He noted that the team is actively recording notes and TODOs from all input received, and that the marking tool is an intentional experiment — future iterations are being considered for PintOS and more fully for WACC (where actual marks will be given). The current iterations have focused more on the tutor-marking/feedback side, but student feedback from the receiver perspective is very welcome.
