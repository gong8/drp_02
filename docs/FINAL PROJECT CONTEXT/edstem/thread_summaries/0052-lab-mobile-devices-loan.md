# #52 — lab mobile devices loan

`source: edstem thread #52`

**Question:** A student asks whether there are any mobile devices available on loan from the labs, noting that the DRP Overview 2026 (page 9) states that mobile apps should run on one of these loaned devices, but that Jamie indicated this information is out of date.

**Answer (Mark Wheelhouse):** Some mobile devices can still be loaned from the TFs and CSG, but they are no longer kept up to date and are not modern. The requirement in the overview document to run your app on one of these loaned devices can be disregarded. The web browser requirement for WebApps remains in force (replace IE with Edge on the list), but that should not be difficult to meet.
