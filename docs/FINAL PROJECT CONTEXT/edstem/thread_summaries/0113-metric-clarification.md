# #113 — Metric clarification

`source: edstem thread #113`

**Question:** A student asked whether the metric tracked that week must relate to the week's theme, or whether it could relate to a feature from a prior week. They also asked whether changes made when measuring the metric need to be thin-slices or can be frontend-only.

**Answer (Mark Wheelhouse):** The metric must relate to something actively being developed that week, but it does not have to align with the week's theme of focus (though it usually will). All development from this point on must proceed via thin-slices — frontend-only changes are not sufficient.
