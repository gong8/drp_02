# #67 — Using a simple vibecoded frontend prototype instead of a paper mockup

`source: edstem thread #67`

**Question:** A student asks whether using a vibecoded digital frontend prototype (e.g. via Google AI Studio) is a valid substitute for paper mockups in Milestone 2, given it can be produced just as quickly but offers greater interactivity.

**Answer (Mark Wheelhouse):** Yes, a vibecoded prototype can form part of the prototyping workflow, but jumping into digital mockups too quickly is inadvisable. Low-fidelity paper mockups tend to elicit a wider range of feedback from users because the solution feels more open to change; moving to a digital format risks reducing that creative freedom.
