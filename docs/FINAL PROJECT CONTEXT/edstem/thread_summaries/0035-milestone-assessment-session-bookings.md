# #35 — Milestone Assessment Session Bookings

`source: edstem thread #35`

**Question:** How and when can students book their Milestone Assessment presentation sessions, and what are the requirements for the Elevator Pitch presentations?

**Answer (Mark Wheelhouse):** The [DRP Milestone Assessment Schedules spreadsheet](https://imperiallondon-my.sharepoint.com/:x:/r/personal/mjw03_ic_ac_uk/Documents/DRP%20-%20Milestone%201%20Assessment%20Schedule%20(read-only).xlsx?d=w5121fcb27e334f74ac82a8e0f5bdfeb8&csf=1&web=1&e=e7xpbO) was opened for editing at 13:00 on Wednesday 20th May. Key points:

- Groups book a slot for Milestone 1 ("Elevator Pitch") and are thereby committed to the corresponding time slots for Milestones 2–4 (29th May, 5th June, 12th June). The session time mapping is:
  - 14:00–15:00 (M1) → 10:00–11:40 (M2–4)
  - 15:15–16:15 slots 1–5 (M1) → 11:15–12:05 (M2–4)
  - 15:15–16:15 slots 6–10 (M1) → 14:00–14:50 (M2–4)
  - 16:30–17:30 (M1) → 14:25–16:05 (M2–4)
- Groups must also enter their **problem domain** and **opportunity statement** into the spreadsheet to help manage overlapping project ideas.
- Presentations are held live in HXLY 311 or HXLY 340 (see schedule for which room). All groups must **pre-record** their elevator pitch (2–3 minutes) and play it via laptop over HDMI or USB-C.
- Presentation order within each session is random and not announced in advance; all group members must attend the full 1-hour session.
- Arrive a few minutes before the session start time. Brief feedback is given after each presentation; detailed feedback follows in DRP Clinic hours and over the weekend.
- All group members receive the same mark by default, subject to moderation if needed.
