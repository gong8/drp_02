# #117 — Metric for milestone 4

`source: edstem thread #117`

**Question:** A student asked whether user satisfaction (rated out of 10, optionally combined with task completion time) would be a valid metric for Milestone 4.

**Answer (Mark Wheelhouse):** User satisfaction is not an objective metric — it is inherently subjective and should be evaluated through qualitative (HCD) methods, not presented as a quantitative measurement. A task-timing metric (timing a specific, context-relevant task) would be a much better choice to track over the course of the week.
