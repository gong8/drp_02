# #116 — Messaging Features

`source: edstem thread #116`

**Question:** A group with a messaging feature in their app asked whether they need to implement all standard messaging UI conventions (e.g. notification dots, unread message indicators), or whether they can deprioritise these in favour of the more context-specific and novel parts of their interaction.

**Answer (Mark Wheelhouse):** Standard/conventional UI best practices are worth following, but handle them in a single thin-slice iteration and then move on to the more important, context-specific parts of the interaction. If any UI elements are distracting users from the core interaction, either fix those elements or reconsider whether they should be present at all.
